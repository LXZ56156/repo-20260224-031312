## 范围与身份

候选入口为“我的”中的次级“找回比赛”，打开独立列表。找回列表不表示成为参赛者，也不触发生产写入；选择一项使用既有赛事打开/同步链路。在已有同步逻辑确认finished文档时，仍按原本机完成快照行为处理；这不能宣传为所有设备历史完整迁移。

云端函数以getWXContext的OPENID为唯一当前身份：creatorId相等表示主办；权威players/playerIds中的实际绑定ID相等表示参与。导入guest、相同姓名、昵称、头像、客户端传来的openid和分享短码均不构成归属。旧数据别名仅按当前player-common的真实ID合同验证，不能按姓名自动补绑定。

getMyPerformanceStats只做finished参与统计/fallback/analysis，最多4000条并报告truncated；它不含仅主办未参赛的全部状态，也不是找回列表API。不能改名或直接拿其统计响应实现本列表。

## 列表合同候选

- 主办/绑定参与两路查询合并，按赛事ID去重；权威记录二次身份过滤。覆盖draft/running/finished，不包含他人赛事；查询失败不能冒充空列表或完整结果。
- 第一版每页20条，按updatedAt降序、_id稳定排序；游标必须绑定身份与排序边界。两路有独立游标，不能只取各自第一页后假称合并分页完整；当某路失败/达到上限时显式结果code/完整性，重试原查询不写赛事。
- 返回只需id/name/mode/status/updatedAt、主办/参与角色标签及显示用完成/总场次数，不返回openid、内部players.id、clientRequestId、分享凭据或完整比分名单。当前打开后的分享读取仍是原合同，本步骤不会自行声称字段隐私已全部解决。
- 找回只是读列表和打开；不批量写本机已完成快照，不删除/覆盖既有本机数据，不用未读取成功的摘要伪造完整赛事。
- 主办者创建后退赛仍可找回；guest后来明确认领绑定后按权威新ID找回；已删除记录不出现，不自动恢复已删除生产文档。
