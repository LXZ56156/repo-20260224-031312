# 小程序 UI 视觉验收门禁

由 AGENTS.md 的 UI Completion Gate 原文集中迁入（2026-09-11），保留门禁强度；只在相关 UI 工作时完整读取。截图命令与会话合同见 [截图工作流](weapp-ui-screenshot-workflow.md)。

日常真实图通过 `npm run ui:iterate -- <case>` 采集，步骤见 [开发工作流](agent-development-workflow.md)。采集失败按 [故障手册](weapp-ui-troubleshooting.md) 恢复；本轮机器成功与主控人工审图分别报告，使用新入口不减少本页验收要求。

向用户汇报 UI 完成前，主控必须亲自检查当前源码的真实微信 DevTools 图；自动量测、结构快照、浏览器稿和旧图都不够。至少检查：

- 操作显著性与主次层级；
- 44px 触达、文字基线/换行和图文间距；
- 对齐、边界、圆角、阴影、裁剪、遮挡和横向溢出；
- 与任务相关的输入、清空、空结果、选中、禁用、加载和大名单状态；
- 需要响应式证据时，先覆盖正常及更大屏幕，机型与尺寸顺序见下节；明确区分真实截图与结构/数学检查。

明显视觉重做、高密度弹层，或用户明确指出“丑、难用、信息挤压”时，还必须执行双盲审：

- 两名 UI 评审收到相同的当前源码实图、产品合同与历史基线，互不读取或引用对方结论；
- 主控必须记录两份报告的共同结论、分歧、采纳/拒绝及理由，再进入最终用户验收；
- 两份报告共同指出的 P0/P1 未关闭前，不得宣称 UI 完成；子代理意见不能替代主控实图检查；
- 高密度选择 UI 先在正常及更大屏幕验收24人、长昵称、搜索空结果、键盘和safe-area；正常机型字体放大按任务相关性安排，小屏及小屏大字按下节暂缓；
- 主 CTA 必须在真实图中验证 ≥44px、全宽/对齐、默认单行；动态摘要不塞进动作按钮；
- 每个弹层每个方向只能有一个滚动 owner，safe-area 只能由一层负责；选择状态不得只靠颜色或伪元素。
- 高密度名单的当前操作侧必须与首屏可见内容一致；切换侧别后至少露出一整行该侧成员，同时提供明确的滚动可发现线索，不能靠 footer 裁掉半行暗示还有内容；
- 截断不得切断人数、单位或状态等语义原子；重复人数应从摘要中移除，完整内容另设可访问的展开入口；关键弹层必须有明确、可访问且 ≥44px 的关闭入口；24rpx 辅助文字按普通文本至少 4.5:1 对比度验收。
- 筛选空态不得继续显示已经失效的“滑动、点选”等操作提示，并应提供可见且 ≥44px 的清除或恢复入口；户外高频页面的禁用关键 CTA 即使不受普通文本对比度硬性约束，也按至少 4.5:1 保证可辨认性。

发现肉眼问题先修复并重跑，不把基础检查留给用户指出。本文件是详细视觉门禁的唯一维护位置。

补充既有核对规则：44px 按实际 viewport 的 CSS px 核对，不能只看 rpx；同一状态最多“主显示 + 一次校验”；选择状态至少使用文字/符号与边框/填充中的两类线索，不能只靠红绿或伪元素。原生 picker、键盘仍需相应真实检查。

## 覆盖清单与通过标准

每个验收目标在现有任务正文维护简明清单：页面/功能、状态或风险、实际版本/环境、结果（已验/未验/阻塞）、截图或断言证据。详情按需展开，不把所有测试日志堆进索引。

- 视觉：按相关页面覆盖正常/大屏、适用字号、长文/大名单、空/加载/错误态、键盘和安全区；优先级见下节。未覆盖设备明确列出。
- 操作：真实点击原生选择/确认/取消，检查保存后重开读回、返回路径、重复点击与恢复；检查步骤是否方便快捷、反馈是否清楚，不仅“截图看起来正常”。
- 数据：按风险覆盖正常、异常、边界、权限、幂等/并发、断网重试、缓存与恢复。离线模拟、隔离 fixture、真实云事务和真机分别记录；不以一种结果替代另一种。
- 问题先修后复验，变化做关联回归，跨链路或基础设施变化按 AGENTS 做必要全量。测试数量、机器 ok、图片生成成功都不能单独代表验收通过。
- 没验到的不能算通过；有阻塞必须说明影响与下一步。持续优化实际使用体验，但不承诺穷尽全部输入或绝对零缺陷；新产品方向和生产操作仍遵循独立授权。

## 机型与尺寸测试顺序

2026-10-12用户明确调整测试优先级，取代原先默认同时覆盖320/390/430及小屏大字的要求：

1. 优先iPhone 16 Pro等正常机型，先验证普通字号下的显示、按钮、原生控件、关键弹层与底部CTA。
2. 随后覆盖更大屏幕、Pro Max等机型。机型名称、逻辑宽度、字体与safe-area以实际设备或DevTools/SDK回读为准；已有390/430证据不能改标为16 Pro已验。
3. 320等小屏幕以及小屏大字暂不安排，不作为当前正常/大屏检查的完成前置。保留已取得的证据和缺陷；只有用户重新要求或问题影响正常/大屏时才恢复对应检查。

正常机型的大字未被整体取消，按相关性在普通字号主流程之后安排。实际键盘、网络、真实身份/云事务与真机性能仍分别验收；本次优先级调整不把未验项改成通过，也不减少正常/大屏的触达、裁剪、滚动归属、双评审及来源要求。

## 设计与历史路线边界

- Web方向翻译为原生WXML/WXSS/JS、系统字体、低端机、44px触达、reduced motion和无远程视觉依赖，不照搬hover、Web字体或浏览器专属CSS。
- 暖米色+酸绿、暗底+荧光绿、报纸规则线及被否决的Next-Gen/C3/Home全面重做只作反例，不继续微调复用；不自动恢复全面Home重做、全局设计系统或跨页面统一。
- codex/ui-optimization-v2、nextgen-integration、nextgen-ui-redesign-20260724及其他next-gen worktree是历史证据，不整体复用、合并或迁移。相关产品批准仅在需要时读 [历史决定](../tasks/incremental-ui-restart-handoff-2026-07-29.md)，当前任务范围仍以current为准。
