### 3. 订阅消息

| 项目 | 内容 |
|------|------|
| 前置条件 | MP后台「功能 → 订阅消息」申请模板 |
| 订阅时机 | 创建赛事后 / 加入赛事后 |
| 发送时机 | 有人加入（人数更新）/ 开赛 / 全部完赛 |
| 涉及端 | 前端 `wx.requestSubscribeMessage` + 云函数 `subscribeMessage.send` |

需要先确认 MP 后台是否能申请到合适的模板。如果不能申请自定义模板，则需使用公共模板库中已有的。
